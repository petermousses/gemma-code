# gemma-code

## 🤖 Description
This repository serves as a **CLI agent harness for interacting with the Gemma 4 model via Ollama**.

It provides the foundational structure for building and running an AI agent that leverages the power of the Gemma 4 model locally.

## 🚀 Getting Started

To get this project running locally, follow these steps:

1.  **Install Dependencies:**
    ```bash
    npm install
    ```

2.  **Build the Project:**
    This compiles the TypeScript source code into a runnable JavaScript distribution.
    ```bash
    npm run build
    ```

3.  **Run the Agent:**
    You can start the agent using the following script:
    ```bash
    npm start
    ```
    *Alternatively, use the development script for live reloading:*
    ```bash
    npm run dev
    ```

## 🛠️ Technology Stack
*   **Language:** TypeScript/JavaScript
*   **Core Functionality:** CLI Agent Harness
*   **AI Model:** Gemma 4
*   **Inference Backend:** Ollama

## 📦 Structure
*   `src/`: Contains the primary source code for the agent logic.
*   `dist/`: Contains the compiled JavaScript files ready to be executed.
